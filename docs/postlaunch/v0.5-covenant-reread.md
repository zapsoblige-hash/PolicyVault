## Method

frozen invariant, and for each ask: where is it enforced, what input could
evade it, and is that input covered by a real-engine test? Two gaps found
were closed by adding engine cases; no covenant change was needed.

## Observations (accepted, not defects)

1. The agent signature's sighash type is not gated (v0.4.1 gates only
   approvals). Every value-bearing output is pinned by the covenant, so a
   non-ALL agent signature could only let a third party redirect the
   agent's OWN change — never vault or token funds. Same posture as v0.4.1.
2. `descriptorHash != 0` is an identity anchor, not a security check.
3. `templateStateLen` is a redundant pin (see table); harmless.
4. Recipients are p2pk-only (scheme byte 0x00 in the leaf) — a frozen v0.5
   scope decision, enforced (`identifierType == IDENTIFIER_PUBKEY`).

## Result

No covenant defect found. Two matrix gaps closed with real-engine cases
(`v5_production.rs` spend matrix now 37 cases). The emitted source matches
the specification; the reread does not change the measured envelope.
