PolicyVault

PolicyVault is non-custodial. This app never holds a seed phrase, a private key, or any signing secret, and it never will — signing happens in a separate signer that keeps custody of its own key.

SCAFFOLD BUILD. Read/coordinate screens and on-device verification only. A real Android debug and release build of this tree has been produced and statically verified (manifest, permissions, backup policy); it has not yet been executed on a device or emulator. No iOS build has been produced.
